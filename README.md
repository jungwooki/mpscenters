# MPS Centers

레슨센터 코치님을 위한 안내 페이지입니다. mps-teams/index.html의 스타일과 섹션 구성을 기준으로 제작했습니다.

- index.html: 리포트, IDP, 센터 활용 안내, 전문가, FAQ, 가격 안내
- pages/dashboard/: mps-centers2의 2026-10-12 최신 대시보드 샘플을 복사한 독립 실행본. 원본 수정은 자동 반영되지 않습니다.
- pages/blog.html: 공통 인터뷰 콘텐츠
- archive/before-team-layout-20261010/: 변경 전 안내 페이지와 스타일

상위 작업 폴더에서 실행:

```sh
python3 -m http.server 8776 --bind 127.0.0.1 --directory mps-centers
```

http://127.0.0.1:8776/ 에서 확인합니다. 상대 경로를 사용하므로 상위 폴더에서 서비스해도 열립니다. 대시보드 데이터는 기존 센터 샘플과 동일하게 브라우저에 저장합니다.

## 센터 관리 기능

- MPS성장단계별 / 학년별 명단 보기, 이름 가나다순 정렬
- 기본 정보의 학년 수정, 검사 도래 선수 패스·복원
- 총·진행·남은 회차, 캘린더 레슨 완료 차감 및 완료 취소 복원
- 상위 영역과 세부 목표를 구분한 IDP 목표 선택

검사 결과·목표·회차·예약은 가상 샘플이며, 이 브라우저에 저장됩니다. archive와 이전 preview.png는 로컬 보관용으로 Git에서 제외합니다.

## 최신 센터 샘플 연결

2026-10-12 수정한 선수 중심 대시보드로 내부 샘플을 갱신했습니다. 소개 미리보기, 대시보드 살펴보기, 샘플대시보드, IDP 및 플로팅 안내 버튼은 모두 pages/dashboard/index.html을 엽니다. 집계 기준과 그래프 스크립트도 포함해 센터 폴더만 서비스해도 실행됩니다.
